AI 热点OpenAI 一次放出九篇论文：矩阵乘法指数就是 9/4，希尔施猜想被推翻

论文

11 月 24 日 openai/math 仓库更新：新增九篇手稿、分属两个结果族，其中「矩阵乘法指数的对数指数是九分之四」给出任意域上精确指数 9/4，直接否掉「指数等于 2」的老猜想；同批「强多项式线性规划」回答 Smale 第九问题，「简单多面体的超多项式图直径」推翻有界简单有理多面体的多项式希尔施猜想。

11-24 公开九篇部分附 Lean发布 2026-11-24

两个结果族怎么分的：族 379「欧氏张量几何及其在复杂性、组合上的应用」七篇，从张量的渐近谱几何出发，一口气推出 Valiant 层级分离、哈密顿回路与永久式的算术电路下界、有限傅里叶变换与多带整数乘法的对数指数、向日葵的指数上界，以及矩阵乘法的 9/4；族 380 只有两篇，强多项式线性规划与多面体直径。仓库说明写明，后两者包含了 11 月 23 日那篇「VP 与 VNP 不同」的结论。

读者的算术：HN 上有人对照 Top 500 未解数学问题榜统计，这批结果牵动 8 个条目——#25 矩阵乘法指数、#89 强多项式线性规划、#64 平均收益博弈、#65 奇偶博弈、#340 Condon 简单随机博弈，以及被否掉的 #183 多面体直径界与 #130 单纯形枢轴规则、被证明的 #137 Erdős–Rado 向日葵猜想。部分结果附了 Lean 形式化。

别急着当成「P=NP 被解决」：这些是渐近结论，常数与指数底数都没优化到工程可用的量级，密码学上的 RSA 也不因此当场失效；而且这是同一个实验室的自发布，独立复现与同行审读都还没走完。真正的看点是「生成—形式化—核验」这条流水线已经能批量产出这种级别的结果。

AI 热点Google 也端出六篇：无条件整数分解进了 L[1/3]，离散对数跌到亚拟多项式

论文

11 月 25 日 google-research 仓库新增 Cogentic 研究论文目录，同日六篇：无条件下整数分解达到 L_N[1/3, O(1)]、固定特征有限域离散对数达亚拟多项式、双矩阵博弈 1/5-近似纳什均衡的精确多项式算法、对数秩猜想的平方根壁垒被打破等，全部 Apache 2.0 放出 PDF。

11-25 公开六篇Apache 2.0发布 2026-11-25

六篇的题目各自对着一个老问题：整数分解那篇把复杂度压到 L[1/3, O(1)]（此前同类算法的 1/3 指数多带条件或不可证明假设）；离散对数那篇在固定特征域做到亚拟多项式；双矩阵博弈那篇给出 1/5-近似纳什均衡的精确多项式时间算法；另外三篇分别处理确定性次指数分解与二次非剩余构造、对数秩猜想的平方根壁垒、线性密度简单图的无条件边重构。

节奏值得注意：这个目录不是今天才有——10 月 30 日一篇（双人凸博弈近似相关均衡的难解性）、11 月 18 日一篇（VC 类近二次样本压缩）、11 月 23 日两篇（次可加先知不等式、虚拟对弈收敛维度），今天直接加六篇。也就是说，两家实验室在过去一周里都在用「批量产出」的方式推进理论计算机科学。

对普通读者最实际的问题是「我的加密还安全吗」：这些结果讲的都是渐近复杂度，L[1/3] 分解的常数项与存储开销远未落地，RSA-2048 不在今天被破的名单里；但路线图变了——如果方法能继续优化，后量子迁移的时间表会被重新讨论。开 PDF 前先记住：内容来自实验室自发布，还没有期刊审稿。

AI 热点Claude 的 Artifact 能装成桌面应用了：自己弹通知、进托盘，全套餐可试

上线

11 月 24 日 Anthropic 上线「Install as app」测试版：在 Claude for Mac / Windows 里把 Artifact 装成独立应用，有自己的图标与窗口，可分享、可开机弹出通知、可驻菜单栏或托盘，改动底层 Artifact 后应用自动更新，需要时重新申请权限。

11-24 测试版全套餐Mac/Win发布 2026-11-24

三档权限是设计重点：默认档只能做浏览器里能做的事；应用权限档可申请置顶窗口、全局快捷键、发通知；完全访问档能运行程序、读写删文件且不再逐次询问。授权只对「当前这一版」有效，Artifact 一改（包括你自己改）就要重批；如果应用里加载了别站代码，那部分代码可以不经再次询问而变化。

上手与门槛：Claude 桌面端升到 6.28899.0 以上，打开 Artifact → 标题菜单或右键 → Install as app。所有套餐都能用，Team 默认开但「完全访问」默认关，Enterprise 要管理员在组织设置里打开；HIPAA 配置、Linux、网页与手机端都不支持。应用里对 Claude 的调用计进套餐用量。

官方给了五个自用示例（分层图像编辑器 Linnet、片场风格文件管理器 Phosphor、文件夹规则 Sift、带讲解的终端 Tern、性能监视 Vitals），意思很明确：知识工作者不用打包、不用签名、不用 API Key，就能把自己每天要点的那个页面变成桌面程序。风险也在这——Anthropic 不审应用，完全访问只该给自己或同组织的人做的东西。

AI 热点Anthropic 把 Messages API 从 Python 搬到 Rust：CPU 省 70%，首字延迟降 20%

工程

11 月 25 日 Anthropic 发文复盘：Messages API 在 2024 年初到 2026 年秋流量涨约 1800 倍，Claude 用约一周写出 Rust 版核心请求路径，最终上线后每请求 CPU 降低约 70%、中位首字延迟降约 20%，全程没有停机、也没冻结功能开发。

11-25 复盘发布Rust 已上线发布 2026-11-25

难点不在写代码，在「怎么证明搬对了」：Python 版在迁移期间一直改，parity 是个移动靶；同一个请求 Claude 的回答本来就是非确定的，两次输出不同不等于有 bug；而且他们读不到用户请求内容，无法人工比对分歧点。所以文章的核心做法是把生产流量本身变成验证器——拿真实请求同时打新旧两版，用差异自动派 agent 去修。

那条曲线值得记住：4 月 Rust 版已经能过约 98% 的测试，但在生产流量上只有约四分之一输入对得上。差距来自测试没覆盖的边角（比如 Python 写 JSON 工具调用时会把 emoji 转义成文本码，Rust 原样输出，两边 prompt 差几个字节）和权重的不同——测试里每个用例算一次，线上一个常见 bug 会在每次触发它的请求里出现。

这条经验对所有「迁生产系统」的团队都成立：生成比核验容易的时代结束了。文章自己给的结论是，能上生产的迁移必须先把判定「正确」的办法做出来，而不是先让模型把代码写快。

AI 应用展现Versine（YC F26）：给 AI 一个钱包，说句话就能转账收款，最高一次 100 人

YC F26

Versine 在 HN 的 Launch 帖里介绍：把钱包放在 MCP 后面，你的 agent 就能替你转账与收款——发钱要用 App 里的 passkey 批准，一次可给最多 100 人发或收，收款方没有 Versine 账号也能取现；团队来自 Stripe、Databricks、亚马逊的分布式系统一线。

2026-11-24 发布美区为主发布 2026-11-24

它想解决的是「agent 会买东西了，但不会结账」：现在购物代理大多止步于把商品加进购物车，付款要人接手；Versine 把授权做成 passkey 确认，让 agent 发起、人来放行，再把「给室友 AA、给合作者结款、收尾款」这类高频动作变成一句话。

风险必须写在明面上：任何「AI 能直接动钱」的服务，出事都不是小钱。看三件事——授权是否每次都要人确认、额度上限是否可设、出问题有没有追回机制。HN 讨论里最集中的质疑也在这三点。

国内读者更该注意的是它跑在什么通道上（美元账户、ACH 一类），跨境转账与合规限制决定了它短期内只能服务美区用户。
