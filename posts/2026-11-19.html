01

AI 热点Genie 4 进 Project Genie：世界玩到一半，打字就能改

已推送

首次开放 Genie 4：边走边输入提示词就能换天气、加角色、改剧情，画面还第一次配上实时原生音频。

发布 2026-11-18

Google DeepMind 今日向符合条件的 Google AI Ultra 订阅用户推送新版 Project Genie：首次开放 Genie 4，同时保留 Genie 3，并带来会自己编排多模态模型的 Project Genie agent 和一个可浏览、可 remix 的社区画廊。

Genie 4 的新东西是「边玩边改」：在世界里走着的时候直接输入新提示词，就能实时改环境——换天气、放进一个角色、改剧情走向；这也是它第一次给画面配上实时生成的原生音频，从环境声到角色对白都跟着场景变。Genie 3 同步升级：单次生成的可探索时长从 60 秒延长到 3 分钟，能把多个世界串成一段长旅程；支持用 360° 全景图做种子；探索中可用自然语言触发世界内事件。

画廊里既有官方策展，也有社区作品与 remix：把个人照片变成可探索空间的「Living Memory」、以 360 全景为底的「Dino Field Guide」、由 Gemini 当实时裁判的「Rock Paper Scissors」，以及与创作者合作的「Villa Giallo」（哥特宅邸逐屋解谜）和「The Life of Ants」。

来源：Google 官方博客 《Genie 4 is now available》 · DeepMind 技术文章 官方未注明截止日期（属订阅功能）

02

AI 热点微软 Ignite 一次发七个模型：Opus 5.5 的 96% 表现，5% 的价格

已发布

MAI Code 2 以约 40% 价格做到 GPT-6.1 Sol 的 98%；图像编辑登顶 Artificial Analysis，价格只有对手五分之一。

发布 2026-11-17

微软 AI（MAI）在 Ignite 上放出七个模型，主线只有一句：让 agent 能 7×24 跑真实工程活，同时把 token 账单压下来。

具体对照：MAI Cyber 2 Flash 在 CyberGym-E2E 上以不到 2% 的单任务成本做到 GPT-6 Astra 的质量，输出 token 比 MAI Cyber 1.1 Flash 便宜 86%；MAI Code 2 在四项企业编码基准（DeepSWE 1.1、Terminal Bench 2.1、SWE-Atlas、FrontierCode v1.1）上平均达到 GPT-6.1 Sol 的 98%、价格约 40%，达到 Claude Opus 5.5 的 96%、价格只有 5%；MAI Code 2 Flash 与 GPT-6 Luna 表现相当、价格 65%，与 Claude Haiku 5.5 相当、价格 20%。

另有：MAI Image 2.7 拿下 Artificial Analysis 图像编辑第一，价格是 GPT Image 2.6 Sunburst（max）的五分之一；MAI Realtime 1 是微软首个实时语音到语音模型，最低每音频分钟 0.01 美元；Decision 1.1 比 GPT-6.1 Sol 快 50 倍、便宜 79 倍。硬件侧，第二代自研加速器 Maia 200 已投产、在跑微软最大的模型，每瓦 token 数提升 1.7 倍。

可用性：MAI Code 2 当天进 GitHub Copilot；MAI Code 2 Flash 在 GitHub Copilot 与 Microsoft Foundry 受限预览；MAI Realtime 1 可在 MAI Labs 试用。官方也承认这批模型还没针对基础科研和超长周期 agent 任务调优。

来源：Microsoft AI《Seven new world-class models at scalable price-performance》

03

AI 热点英伟达董事会拒绝黄仁勋复职，CFO 代理 CEO

已确认

董事会一致接受辞呈、不打算让他复任；同季营收 1160 亿美元同比翻倍，盘后股价涨 5.2%。

发布 2026-11-18

英伟达董事长 Harvey Jones 在第三季度财报电话会开场说，董事会「一致接受了他的辞呈，不打算让黄仁勋复任 CEO」；他会尽快找到常任 CEO，但不会为了速度将就。目前由 CFO Colette Kress 代理，公司照常运转。

此前一天，黄仁勋在社交媒体表示：如果董事会认为他回归符合股东、员工、公司与国家的最佳利益，他「很荣幸回应这些呼声」，同时承认在个人生活中犯了「严重错误」。美国总统与多位硅谷人士公开支持他回归，也有科技界人士联署请愿。

财报本身很硬：第三季度营收 1160 亿美元、同比翻倍；每股净利 2.70 美元，高于市场预期的 2.48 美元；盘后股价涨 5.2%。公司同时宣布新设一个负责国家安全与贸易合规的董事会委员会——背景是有关 AI 芯片疑似走私中国的调查。

来源：AP 报道（Slashdot 转载） · Solidot 中文摘要

01

AI 应用雪迹 Cold Smoke：1.7MB 的单文件滑雪游戏，山、极光、风都是代码现画

在线 · 免费

一个 HTML 文件装下整座雪山，没有一张贴图、一段音频；每天所有人滑同一条「今日雪山」。

打开即玩，无需登录发布 2026-11-14

开发者 huiskylabs 用 Fable 5.2 做出这款主打放松的 3D 滑雪游戏，11 月 14 日上线：整个游戏约 1.7MB、单个 HTML 文件，没有图片、音频、模型或贴图文件——雪山、树林、天空、极光、滑雪者、背景音乐和风声全在运行时由代码生成。

玩法很干脆：方向键控制方向、空格起跳、Shift 收身加速，从白天滑到黑夜；没有排行榜，也没有需要解锁的装备。「今日雪山」每天生成一条所有人共享的同一条雪道。

中英双语，桌面浏览器（WebGPU 或 WebGL2）体验最好，免费、打开即玩。

站点：PlayBloo《雪迹 · Cold Smoke》 · 发现帖：V2EX

02

AI 应用HADAL：Perplexity 同事用 AI 写的 373KB 下潜游戏，一路潜到马里亚纳海沟底

在线 · 免费

没有引擎、没有 Three.js、没有素材：WebGPU 渲染器手写，地形、生物、潜艇和音效全由代码生成。

浏览器直接玩，无需安装发布 2026-11-17

这是 Perplexity 团队成员用 Claude Fable 5.2 做出来的浏览器下潜游戏，Aravind Srinivas 在 X 上放出地址：你带着一艘潜水器从海沟顶部的珊瑚礁出发，扫描发现物、采集矿物样本换「测量点」，再用点数换更耐压的耐压壳，一层层往更深处走，最后在 Challenger Deep 海底放下信标。

技术上没有用任何游戏引擎，也没用 Three.js：渲染器是手写 WebGPU，地形、海藻、生物、潜艇模型和音效全部由模型生成，不导入任何模型、贴图或音频文件，整个游戏就一个 373KB 的 HTML。据作者推文，这次一共花了 36,000 个 Perplexity credits，由 Ultra Effort 模式下的 Fable 5.2 High 当编排者。

深度计是压缩过的：屏幕上约 430 米的场景代表真实的 10,935 米海沟。机器弱可在设置里降画质和分辨率。

站点：mariana.pplx.app · 报道：AITOP《Perplexity 团队用 Fable 5.2 生成 373 KB 浏览器游戏 HADAL》

03

AI 应用Homecraft：把自己的主页做成一座「我的世界」3D 小院

在线 · 开源

MIT 开源模板，访客在你的体素小屋里走动、看作品与链接；社区已经用它搭出 17 个站点。

MIT 许可 · 可直接 fork

项目由 terryHu7 发起、在 GitHub 以 MIT 开源：把平面个人主页换成体素（Voxel）风的 3D 场景，访客进去能走动，看你的介绍、作品与链接。作者自己的站点 terryhu.cn 就是样板。

社区已经用它做出了府邸大宅、游乐场、长安街、一人公司虚拟空间，甚至把西湖搬进主页——公开案例里有 heikeji.com、zhaur.com、rsliyu.com、xinglong.tech、hbljx.github.io、murphy.red、wyc21.com 等。仓库 10 月 24 日建，11 月 18 日还在更新，现在约 278 个 star。

门槛不高：浏览器端 3D 渲染，不用装客户端；模板开源，改起来就是挪方块、换贴图位置，适合拿来做个人品牌页或作品集。项目介绍里说 AI 生成的内容已按社区规范标注。

站点：terryhu.cn · 仓库：terryHu7/homecraft · 报道：80aj（2026-11-18）
