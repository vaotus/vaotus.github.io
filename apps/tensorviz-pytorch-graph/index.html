tensorViz：让 Claude Code、Codex 看见你的 PyTorch 模型长什么样

在线 · 开源免费免费MIT 开源发布 2026-11-20

11 月 20 日上 Product Hunt 的开源小工具：不用 torch.export、不用转 ONNX，装个 VS Code / Cursor / VSCodium 扩展，或 Claude Code / Codex 插件，点一下「Open as Graph」，它就跑一次真实的 eager 前向，把模型画成可展开的交互图——每个模块、每个张量的形状都是实测值。

对写代码的 agent 意义在于：以前它只能读你的 Python、猜形状；现在能「看」这张图——get_graph、inspect_nodes、propose_edit，改完给你一份 diff 和图上的对比，你接受或丢弃。它还能逐层对比两个版本，专门用来抓 shape mismatch（官网示例里 64 对 128 的错只差一个数）。

免费、MIT 开源，核心功能不需要任何 AI 订阅或 key；不想装也能在 Model Explorer 里浏览 560 多个论文模型的图。短板：捕获走 CPU，平台以 macOS 和 glibc Linux 为主，Windows 只在 Codex 里支持。

站点：tensorviz.dev · 源码：GitHub · Product Hunt tensorViz 捕获为 CPU 前向 · 需编辑器或 agent 插件
