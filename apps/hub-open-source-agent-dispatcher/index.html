Hub：同时跑 100 个 Claude Code / Codex 会话，像跑 5 个一样

PH 第一11-26 发布开源免费发布 2026-11-26

解决什么：同时开很多 Agent 会话时，人会在多个终端之间丢上下文；Hub 把「目标 → 任务 → 决策」收敛成一个队列，每个 Agent 可单独设模型与思考强度（日常用便宜模型、重活用大模型）。

现实限制：官方标注实验性——Agent 默认不弹权限确认；笔记本合盖会暂停、开盖续跑，过夜任务建议放 4GB 内存以上的小服务器，用 --server 模式，手机照样审批。

适合谁：已经有订阅、想让多个编码 Agent 并行的人；不适合把生产仓库直接交给它跑无人值守，先把权限与分支隔离做好。
