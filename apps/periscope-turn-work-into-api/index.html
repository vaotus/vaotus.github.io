Periscope：描述一件事就给你一个接口，agent 在云桌面上替你在旧软件里点

PH 第 411-27 PH 当日第 4免费档每周 10 次发布 2026-11-27

想解决的：很多活卡在「只有人会在某个老系统里点」，agent 走到这一步就断；把这类操作包成接口，agent 才能把流程跑完。创始人说这半年他见的非科技行业公司大多还没用上 AI，活都在没有 API 的旧软件里。

要问的问题：它靠屏幕操作，不是底层接口，页面改版、验证码、弹窗都会影响稳定性；目前运行记录只有分步日志、还没有截图（创始人说会加）。

适合：内部小工具、重复的网页录入、抢时间的手工流程；生产链路先别压上去，拿它做原型。
