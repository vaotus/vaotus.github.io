像素坊：140 万张 CC0 像素素材，中文搜「饺子」能出 629 张

免费工具站免费无需注册发布 2026-11-17

11-17 在 LINUX DO 上被作者 zjxx 贴出来的站，11-22 还有人回帖说「刚用上」：像素坊把做像素游戏要用的东西塞进一个网页——图库、生图、动画、打光、特效、音效。

最实用的是图库：140 万张 16×16 像素小图，全部 CC0、商用不用署名，支持中文按意思搜（搜「饺子」翻出 629 张）。其次是打光：传一张像素图，自动生成法线贴图与光照遮罩，拖着光源当场看效果，导出直接进 Godot、Unity、GameMaker。

它还打包了做《借百鬼》时用的 6 个 Codex / Claude Code SKILL，以及一批开源特效与音效镜像。对想做像素小游戏又不会画画的人，这等于把「素材门槛」削掉一层。
