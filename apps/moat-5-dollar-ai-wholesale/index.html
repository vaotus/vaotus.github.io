Moat：5 美元/月的「AI 批发部」，想替掉 OpenRouter

模型路由11-26 HN 198 分发布 2026-11-26

模式：把大量会员的用量汇成池子去谈批发价，收固定月费 + 按 token 的批发价；10 美元/月「goat」档给 100 美元用量再转 list price。官方称所有模型满血、自己跑 benchmark。

要验证的：所谓批发价是否长期低于官方 API、池子高峰会不会限速、模型版本是否与官方同步。HN 讨论里对「无限量」的可持续性最怀疑。

适合谁：每月 API 花费超过几十美元、又不想被单一供应商锁定的开发者；先用小流量对比同一提示词的质量与延迟，再决定要不要把生产切过去。
