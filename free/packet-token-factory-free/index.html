packet.ai Token Factory：三个模型全免费一个月，不要信用卡

限时免费免费首月需手机验证核对 2026-11-21

GPU 云 packet.ai 上线了自己的推理接口 Token Factory，官方页写得很直白：三个模型「上线首月免费」，之后按每百万 token 计费。免费的是 DeepSeek V4.1 Flash（NVFP4 量化，1M 上下文、支持图片输入、MIT 许可）、MiniMax M3.1 Flash（1M 上下文，主打智能体与代码）、Qwen2.5 1.5B Instruct（32K，小任务）。
