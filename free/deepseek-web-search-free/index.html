DeepSeek：模型自己联网搜、抓网页，不单独收费了

长期生效2026-11-18 12:00 起未注明截止日期发布 2026-11-18

DeepSeek 官方文档写明：自北京时间 2026 年 11 月 18 日 12:00 起，调用模型时触发的服务端搜索、网页抓取，工具调用本身不再计费，返回的内容拼进上下文按 Token 用量算钱。

触发场景有三种：联网工具、Anthropic API 的 web_search 工具、Responses API 的 web_search 工具。DeepSeek Harness 里把「网页搜索提供方」设成 DeepSeek 服务端搜索或「自动」（默认值）时也算免费。

注意边界：在代码里直接调 Search API / Fetch API 仍按次收费，每 1000 次成功请求 5 元，只有「模型自己决定去搜」这条路免费。

来源：DeepSeek API 文档 《模型 & 价格》 · 《网页搜索与抓取》
