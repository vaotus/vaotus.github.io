AI 热点智谱 GLM-5.4：28 层跑两遍的 Loop Transformer，750B 号称对标 2–3T

新模型

11 月 23 日智谱发布首款 Loop Transformer 旗舰 GLM-5.4：把基座 28 层循环两轮，在参数量不变的前提下加深推理，官方称智能水平达到 2–3T 级模型；即日起向 GLM Coding Plan 全量用户开放，同步上线 ZCode、Trae、WorkBuddy、Qoder，API 与权重待安全评估后放出。

已上线 Coding PlanAPI 待开放发布 2026-11-23

架构上有三处实打实的工程改造：门控渐进更新，第一轮先建全局上下文、用较小的门值温和写回，第二轮再放开写回做精炼，并按 token 难度调步长；KV Cache 全局共享加滑窗独立，多循环一轮只多一个窗口的 KV，1M 上下文下部署成本才控得住；稀疏注意力索引只算一次，第二轮直接复用。

效果口径要说清：官方只在 30B 同参数模型上给了对照实验（总训练算力只多约 10%），提升最大的是数学、科学推理与长上下文，GPQA、MMLU-Pro 等基准上平均输出长度还降了 10%–14%；750B 本身没有公开基准分，第三方也还没有独立评测。速度非高峰最高 200 token/s，高峰 70–80。

用法：11-23 起 Coding Plan 全量可用，V2/V3/团队版用户用它的额度提到 1.5 倍；官方自己也承认它容易陷进过长的「马拉松式思考」循环。API 和开源权重都要等安全硬化，订阅前先确认你本来就在用编码套餐。

来源：Z.ai 《GLM-5.4: Toward Generalized Coding》 · 中文文档 GLM-5.4 750B 无公开基准 · 数字为官方口径

11 月 23 日沃尔玛的 Agent Gateway 上线，Meta 的 Muse 成为第一个接入的代理：能在 Walmart.com 与 Sam's Club 找货、加购、结账，价格与人类相同；你在自己的 Walmart 账户里建「Agent Profile」，设消费上限、审批与消费记录。

11-23 上线首个接入是 Muse发布 2026-11-23

流程只有三步：告诉 Muse 要买什么（比如「找几个能送到家的黑五电视优惠」）→ 它带你去 Walmart 登录，再回到对话 → 第一次加购时建 Agent Profile 并设消费上限，之后用 Walmart 账户里存的卡在对话里结账。价格与 Walmart.com 一致，退货政策照旧适用。
