蚂蚁开源 Ling-3.2-air：1240 亿参数只激活 55 亿，SWE-bench Pro 翻倍到 58.28

开源MITHF / ModelScope 已开源发布 2026-11-24

官方给的对比全部对上一代 Ling-3.0-flash-VL：SWE-bench Pro 从 26.40 升到 58.28（+31.88），HLE 从 21.96 到 31.42，AutomationBench-AA 从 15.7% 到 61%，SkillsBench 从 42.91 到 67.82；知识工作评测 AA-Briefcase v1.1 的 Elo 从 987 升到 1340。

多模态侧：BabyVision 从 51.80 到 66.49，MathVision（w/CI）从 84.31 到 95.66，Vision2Web 从 57.69 到 80.73，GDP.pdf 任务全通过率从 8.4% 到 16%。这些分数都是厂商自报，社区复现还没出来。

怎么读：MIT 许可加 5.5B 激活，让它成为「私有化部署或租算力」之间比较现实的一档；但估显存要按 1240 亿的全量权重算，只按激活参数估算会严重低估。它在 Qoder 里也能选到（Qoder 的 HungerG 是另一个匿名模型，别混）。
